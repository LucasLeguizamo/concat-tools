# CONCAT Google Gateway: documentation

A hosted gateway between your agent and Google. You sign in once; the agent never sees Google tokens. **Read-only.** Two doors to the same catalog: MCP (Streamable HTTP) and the `concat` CLI.

- [Quickstart](quickstart.md): connect in 5 minutes (hosted, Claude Desktop/Code, Cursor, CLI).
- [Modules and extra permissions](modules.md) (generated): which scopes each module requests and what the error says when a permission is missing.
- [Tools reference](tools.md) (generated): name, parameters and CLI command of every tool.
- [Actionable errors and exit codes](errors.md).
- [Security and threat model](security.md).
- [API tokens for n8n and CI](api-tokens.md).
- [Self-host](self-host.md): your own Google Cloud project, Postgres and Vercel.
